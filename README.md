# Pranay Waghmare — Portfolio

A responsive, static portfolio hosted on GitHub Pages. No build step or external UI dependencies are required.

## Local preview

From the repository root, run `python -m http.server 8000`, then open <http://localhost:8000>.

## Content

- `index.html`: profile, projects, experience, education, skills, and certificate verification links.
- `styles.css`: responsive layout, accessible focus states, and reduced-motion support.
- `assets/certificates/`: Databricks certificate preview and original PDF, plus the Dataiku certificate image.

Certificate images and the Databricks PDF are public portfolio assets. Verification links point to the issuing platforms. The Dataiku URL is transcribed from the supplied certificate.

## Verification

Check desktop and mobile layouts, keyboard navigation, the expandable experience section, certificate links, and local assets before publishing. All content and navigation work without JavaScript.

GitHub Pages serves the repository's configured publishing branch; local changes are not live until published through that workflow.
